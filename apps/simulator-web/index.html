HomeCooked · catalog 0.1.0

Appliance simulator

Spawn any Tier-A catalog class (grouped picker), write settings, tick simulated time, run a procedure / recipe, exercise the fridge→DHW thermal plant demo, or one-click the thermal→dishwasher orchestrator. WASM wraps homecooked-sim, homecooked-procedure, and homecooked-thermal.
